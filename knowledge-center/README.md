# Knowledge Center

This directory is maintained by the AI assistant (Agent) to catalog useful context, architectural decisions, and learnings gathered throughout the development of the Workspace Lifecycle project. 

The goal of this directory is to serve as a persistent, long-term memory bank. As new types of agents or workflow structures are introduced into the project, their responsibilities, context, and structural quirks should be documented here in their own respective files.

## Current Catalog
- `Multi_Agent_Loop.md` — Explains the dynamic, parallel agent structure and signaling flow.
- `Jira_Integration.md` — Technical details on how we orchestrate the Epic/Story lifecycle in Jira.
- `Temporal_Architecture.md` — Core concepts of the Workflow/Activity separation used in this project.
